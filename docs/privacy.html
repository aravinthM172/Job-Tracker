Privacy Policy

Last updated: 1 September 2026

This Privacy Policy describes how the "Job Application Tracker" application ("the App") handles data. The App is a personal project operated by its author for a fixed, private set of the author's own mailboxes. It is not a commercial service and is not offered for use by the general public.

Data the App accesses

  • Google account data, via the https://www.googleapis.com/auth/gmail.readonly scope: read-only access to email messages and settings, used to read message subjects, senders, dates and bodies in order to identify job-application-related emails.
  • Microsoft account data, via the Mail.Read and User.Read scopes: read-only access to Outlook mail and basic profile information, for the same purpose.

How the App uses the data

Message metadata and text are processed solely to classify job-application emails and to extract the associated company name, role, and status. The results are written to a local database that powers a private dashboard. The data is not used for advertising, is not sold, and is not used to build profiles for any purpose unrelated to the features above.

Storage and retention

  • OAuth tokens are stored locally on the machine running the App and are used only to call the Google and Microsoft APIs.
  • Extracted application data (company, role, status, email subject/body, links, timestamps) is stored in a local SQLite database on that same machine.
  • Data is retained until the operator deletes the database or revokes access.

Sharing

The App does not transmit Google or Microsoft user data to any third party. Data flows only between the operator's machine and Google/Microsoft APIs. No humans other than the operator can read the data, and it is not used by any AI/ML model.

Limited Use disclosure

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions or Microsoft account privacy. Revoking access stops all further data collection.
