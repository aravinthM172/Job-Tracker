Job Application Tracker

A personal tool that reads a private set of Gmail and Outlook mailboxes, detects job-application emails (application received, assessment, interview, rejection, offer), and builds a dashboard of application status from them.

It is operated privately by its author for their own mailboxes and is not offered as a public service.
